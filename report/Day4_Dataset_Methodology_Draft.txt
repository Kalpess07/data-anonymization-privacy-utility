2. METHODOLOGY OVERVIEW

The planned workflow consists of the following stages. The exact transformations and evaluation choices will be confirmed with the team before experiments are described as completed.

Stage 1: Dataset inspection and preparation
- Load the selected dataset using pandas.
- Inspect column names, data types, missing values, duplicates, and basic distributions.
- Identify the target variable and separate it from the input features.
- Document preprocessing decisions so that the experiment can be reproduced.

Stage 2: Baseline model
- Train the agreed baseline machine learning model or models on the original prepared data.
- Use a consistent train/test split and evaluation procedure for comparisons.
- Record the model name, preprocessing steps, random seed where applicable, and evaluation metrics.
- Obtain and verify baseline results with Prathamesh before adding numbers to the report.

Stage 3: Anonymization
- Apply the transformations agreed upon by the team to copies of the original data.
- Potential Level 1 transformations discussed in the project plan include direct-identifier removal, age bucketing, and postal-code masking.
- The Level 2 phase is planned to investigate generalization and suppression together with k-anonymity experiments, including k values selected by the team.
- The final rules, quasi-identifiers, and privacy checks must be confirmed with Dhiraj and Sushant. Do not describe the prototype's simple masking as a formal privacy guarantee.

Stage 4: Retraining
- Apply the agreed preprocessing consistently to the anonymized dataset.
- Retrain the selected model or models using the same evaluation protocol as the baseline.
- Avoid data leakage by fitting preprocessing steps only on the training data where appropriate.
- Log each experiment's configuration and results immediately.

Stage 5: Comparison and reporting
- Compare baseline metrics with the corresponding anonymized-data metrics.
- Report absolute and relative changes only after calculating them from verified results.
- Prepare tables and plots showing model utility across anonymization levels.
- Discuss privacy limitations separately from predictive performance; accuracy alone does not measure re-identification risk.
