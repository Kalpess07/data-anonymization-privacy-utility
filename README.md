# Hide Personal Data and Still Use It

## An Empirical Research Investigation on Data Anonymization Techniques: Evaluating the Privacy-Utility Trade-off in ML Models

**Internship Program | Problem 18 | 9 September 2026 – 9 December 2026**

---

## 1. Project Overview

Data-driven work in sensitive domains such as healthcare, finance and government has to balance two needs: individual-level data is analytically valuable, but personal privacy must be protected, both ethically and legally.

This project takes a real, publicly available dataset, applies anonymization techniques such as generalization, suppression, masking and k-anonymity at three increasing levels, and measures empirically what each level costs in machine learning model performance.

The aim is to understand and evaluate the **privacy-utility trade-off** between protecting personal information and maintaining useful data for machine learning.

---

## 2. Objectives

1. Apply anonymization techniques such as generalization and suppression to sensitive fields of a real dataset.
2. Understand and apply k-anonymity at a basic level.
3. Train the same machine learning models on the original and anonymized data and compare the results.
4. Compare multiple anonymization levels: Low, Medium and High.
5. Study the privacy-utility trade-off and understand re-identification risks that anonymization does not fully remove.
6. Develop a research report and position paper on responsible data practices.
7. Develop a Streamlit application for anonymizing CSV files.
